⑨ 量化选股

        

          默认按短线选股标准做技术初筛（趋势/量能/位置/风险）+ 双均线回测 → 综合分；接口 POST /research/sector-screen（screen_mode=short_term）。需长时间联网，填好后点一次并等待。非投资建议。
        

        

          短线初筛条件（默认已启用，与④信号逻辑对齐的简化版）
          
    
            
  • 趋势：收盘 > MA20 > MA60；优先收 > MA5 > MA10 > MA20；MA20 斜率向上。
    • 
            
  • 动能：近 20 日收益 > 0；近 5 日不明显走弱。
    • 
            
  • 位置：距 60 日高点 ≤ 12%（贴近新高加分）。
    • 
            
  • 量能：末根成交量 / 20 日均量 ≥ 0.85；20 日/60 日均量比 ≥ 0.8。
    • 
            
  • 风险：60 日回撤 ≤ 18%；20 日年化波动 ≤ 45%。
    • 
            
  • 候选表展示 短线分、5 日涨跌、末根量比等；初筛列 = 是否通过上述短线条件。仅要旧规则可在 API 传 screen_mode=legacy。
    • 
          

        

        

          四步操作指引（点击展开）
          
    
            
  1. 先定分析谁：默认全市场股票池（两格都空）— 按当前数据源的股票列表顺序取 200 只做评估；要限定则填指定板块 或 自定义代码（二选一）。
    2. 
            
  2. 再定数据从哪来（第 2 步）：数据源下拉中：上面分组为接口数据源；底部分组为本地热门快照（展示/刷新文件，仅影响下方快照表）。默认推荐 mootdx（通达信列表 + 批量行情展示现价）。
    3. 
            
  3. 第 3 步：查看上次选股结果（本机缓存，不联网）或点联网 API 选股评估拉最新日线并回测；下方为板块表与候选股票表。
    4.

数据源与本地快照

            

            

              接口侧：选数据源、股票类型（多选）与右侧策略筛选下拉（可选）后，点「运行选股评估」。全市场默认最多完整评估 200 只；若在下拉中选择了策略条件，则先在全市场列表上按顺序至多扫描「策略扫描上限」只，在其中只保留末根 K 线满足条件的标的，再按策略强度取前 200 只做初筛与回测，结果表按强度优先排序，并附带策略对照列。文件侧：底部「本地热门快照」用于 hot_market_snapshot.json 与下方表。
            

            

              各数据源简要说明
              

                baostock：日 K 走 Baostock；热门板块 / 成分股与 akshare 一样走东财。若常断连，可试 mootdx（通达信板块）或第 1 步「自定义代码」只拉日线。
              

            

            

              

                

                  
                  
                

                

                  
                  

                    
                    

                      
                      
                      
                      
                    

                  

                  
                  
多选为「并集」：满足任一已选板块且通过排除 ST 的代码。未启用策略筛选时，按列表顺序取满 200 只再拉日线；启用策略时见右侧「策略扫描上限」。

                

                

                  
                  
                  

                    
                    
                  

                  
启用策略时：在扫描范围内对每只有效日线算末根是否满足条件；满足者赋予策略强度并排序，再对前 200 只完整初筛与回测。双均线＝末根金叉；三均线＝末根多头排列；站在五日线＝末根收盘≥MA5，表列站上MA5次数；连续3日站上且不跌＝最近连续至少 3 个交易日收盘≥MA5 且每日收盘不低于前一日，表列连续站上天数（适合 3～4 日顺势）。

                

              

              

                候选表「初筛」列含义（与股票类型入池不同）
                

                  初筛（是/否）：对每只股票在请求的起止日期内用前复权日线做技术面硬判断（代码
                  evaluate_screen）。须同时满足：① 最新收盘 > MA20 > MA60；② 近 20 个交易日收益率为正；③ 距 60 日滚动最高价 ≤ 12%；④ 近 60 日最大回撤 ≤ 18%。数据不足 120 根有效 K 线的股票会跳过。未通过时综合分仍会算，但会乘以 0.75 降权。
                

                

                  依据说明：未通过时，服务端会附带文字摘要（均线/新高距离/回撤/波动/量能等），在候选表中将鼠标悬停在「否」上可查看；通过时摘要为「趋势、量能和风险指标均达标」类表述。
                

                

                  与上方「股票类型」的关系：股票类型 + 排除 ST 决定全市场列表的扫描范围与顺序；未启用策略时顺序取满 200 只进入分析。启用策略时在该范围内按「策略扫描上限」扫描后再截 200 只。初筛列仍由技术面硬条件决定，与入池方式无关。
                

                

                  与「策略筛选」的关系：全市场且启用策略时，先在「策略扫描上限」内顺序拉日线，仅保留末根满足条件的标的，按策略强度取前 200 只再做初筛与默认回测，表按强度优先排序；未启用策略时仍为先取满 200 只再评。候选表「双均线·*」「三均线·*」为独立回测列。
                

                

                  结果缓存：联网 API 成功后完整结果会写入本机；之后点「查看上次选股结果」可直接打开，无需重复拉网。改筛选条件后需再点「联网 API 选股评估」重算。
